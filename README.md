## Tweet-CLI: Tweet from the terminal
A Python tool to post tweets from the CLI using Selenium. Requires a Twitter account and a 4-digit passcode for security. No fluff—just a functional script for automation enthusiasts.

`.env` file:
```
TWITTER_USERNAME=username
TWITTER_PASSWORD=twitter_password
TWITTER_PASSCODE=9798
```
